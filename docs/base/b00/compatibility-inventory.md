## Rules for the migration

Spec 0009 requires every identifier and payload below to survive a module move. Until B01 decides an owner, the future owner is **pending B01** and the future identifier is **the current identifier unchanged**. `pending B01` is not permission to rename or move a contract.

| Current owner / surface | Future owner / identifier | Current consumer(s) | Compatibility and retirement |
| --- | --- | --- | --- |
| `platform`, `commerce/*` Command, Query, Event, Job descriptors | pending B01 / exact current string | Runtime registration (`packages/platform/kernel/src/runtime.ts:99-119`); API controllers; worker; CLI; extension handlers | Preserve descriptor name, Zod input/output and event/job payload. No adapter or retirement currently authorized. B17 must exercise every listed identifier before a removal proposal. |
| Extension manifests, `ext.<extension-id>.*`, provider keys | pending B01 / exact manifest id, provider `<kind>:<id>`, and prefix | Extension host and bridge (`packages/platform/kernel/src/extension-host.ts:76-249`, `apps/api/src/controllers/extensions.controller.ts:31-105`) | Preserve prefix and manifest declaration/registration equality. Any replacement needs a time-bounded adapter and a consumer-zero check; none exists. |
| REST, storefront, health and MCP URLs | pending B01 / exact verb + path | Admin, storefront browser, providers, MCP clients; controller source below | Preserve URL, response type/envelope and guard classification. Do not redirect or remove before B17 contract regression and explicit retirement decision. |
| `@storeweave/extension-sdk` exports | pending B01 / exact exported symbols | Eight in-tree extensions and their tests | Keep the entrypoint and structural types stable. B01 may add a separately-versioned base SDK; it must not silently change this SDK. |
| `commerce.yaml`, environment keys and `commerce` CLI | pending B01 / exact key/command | API/worker bootstrap, system operator and release scripts | Keep parsing/defaults and command semantics. A config/CLI rename needs an explicit deprecation window and migration command; none exists. |

All bus descriptors use their declared Zod schemas as the public payload source; do not infer a payload from a controller mapping. `defineCommand` and `defineQuery` retain their schemas in `packages/platform/contracts/src/descriptors.ts:18-108`; `defineEvent` does so in `packages/platform/contracts/src/events.ts:8-21`.

### Extension bridge

The bridge exposes one bounded route family: `GET /api/v1/extensions`, `POST /api/v1/extensions/:id/commands/:command`, and `GET /api/v1/extensions/:id/queries/:query` (`apps/api/src/controllers/extensions.controller.ts:11-105`). It accepts only an exact mounted `id`, requires names beginning `ext.<id>.`, forwards command JSON unchanged, and drops undeclared query-string keys before strict Zod parsing. Its response remains the common `ok(...)` envelope.

Current manifest ids: `demo-erp`, `ecpay`, `ecpay-invoice`, `ecpay-logistics`, `mcp`, `mock-invoice`, `mock-notification`, `mock-payment` (`packages/extensions/*/src/index.ts`).
