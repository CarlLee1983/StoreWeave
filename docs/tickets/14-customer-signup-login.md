# 14 — 顧客註冊、登入與登出

**What to build:** 訪客可以用 email 與密碼註冊成為會員、登入、登出。顧客的領域資料有了落腳處，但生日、等級與點數等欄位在後續票才用得上。帳號與 session 沿用平台既有的那一套，不另寫一份密碼雜湊。

**Blocked by:** 11

**Status:** ready-for-agent

- [ ] 訪客可註冊，重複的 email 在送出前就得到提示
- [ ] 會員可登入取得 session、可主動登出
- [ ] 顧客的領域資料屬於商務模組，平台的帳號模組不含任何顧客專屬欄位
- [ ] 登入嘗試受到節流保護
- [ ] 登入後的身分是顧客型別，稽核紀錄分得出來
