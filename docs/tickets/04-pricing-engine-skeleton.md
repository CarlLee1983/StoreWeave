# 04 — 定價引擎骨架與滿額折固定金額

**What to build:** 有一個純函式的定價引擎：餵給它商品行、情境與當下時間，它回傳每一行的價格調整與訂單總額。第一種規則型別「滿額折固定金額」可用。引擎不碰資料庫、不讀時鐘、沒有副作用，因此可以用大量案例在毫秒內驗證。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 引擎接受商品行、開放結構的情境物件與當下時間，回傳調整明細與總額
- [ ] 滿額折固定金額規則正確：剛好達門檻、差一分、遠超過門檻三種情況都有測試
- [ ] 門檻一律以商品小計判斷，不含運費與稅
- [ ] 引擎沒有任何資料庫、時鐘或隨機來源的相依
- [ ] 規則型別的分派方式讓新增型別不需要改動引擎核心流程
