# 12 — 訂單查詢依身分限縮範圍

**What to build:** 顧客只看得到自己的訂單。以訂單號查詢時，不再對匿名或其他顧客放行。後台角色不受影響。這修掉一個既有的漏洞：任何人猜到訂單號就能讀到別人的訂單。

**Blocked by:** 05

- [x] 前台下單後的訂單確認頁在新的授權模型下仍可用
- [x] 顧客身分查詢訂單時一律加上該顧客的條件
- [x] 匿名身分無法以訂單號取得任何訂單
- [x] 後台角色查詢訂單的行為不變
- [x] 有測試明確涵蓋「以他人訂單號查詢被拒」
