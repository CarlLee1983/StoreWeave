# 28 — 購物車結帳轉單

**What to build:** 顧客可以一次買多件商品：購物車轉成訂單、當場定價並凍結、驗證可售量、結帳成功後車被清空。購物車識別碼成為冪等鍵，重複送出只會產生一張訂單 —— 這修掉一個既有缺陷。

**Blocked by:** 15, 21, 25

**Status:** done

- [x] 購物車轉成訂單，帶入所有商品行並凍結金額
- [x] 同一個購物車重複送出結帳只得到同一張訂單
- [x] 庫存不足時結帳失敗，訊息指出是哪一件商品
- [x] 結帳成功後購物車被清空
- [x] 未登入結帳被拒並引導登入

**做法備註**：前台 `POST /checkout` 的改寫留在工單 29 一次做完（那裡才有購物車頁），
本票交付的是領域命令 `commerce.order.checkoutCart` 與 REST `POST /api/v1/cart/checkout`。
