# 18 — 密碼重設與改密碼撤銷 session

**What to build:** 忘記密碼的會員可以透過 email 收到重設連結，設定新密碼；連結有時效且只能用一次。主動改密碼或完成重設，都會讓其他裝置的登入失效。

**Blocked by:** 06, 14

**Status:** ready-for-agent

- [ ] 請求重設一律回覆中性訊息，不透露 email 是否存在
- [ ] 重設 token 只存雜湊，有時效、單次使用、用過即作廢
- [ ] 重設或改密碼成功後，該帳號其他所有 session 失效
- [ ] 重設信經由通知 Provider 寄出，測試以開發用實作斷言內容
