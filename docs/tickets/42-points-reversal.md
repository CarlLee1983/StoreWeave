# 42 — 訂單取消時購物金回沖

**What to build:** 訂單取消後，折抵掉的購物金回來，那張單累積的購物金被扣回，而且餘額不會變成負數。回沖是寫一筆反向分錄，不是把餘額加減回去。

**Blocked by:** 40, 41

**Status:** done

- [x] 取消時折抵的購物金以反向分錄回沖
- [x] 該訂單累積的購物金以反向分錄扣回
- [x] 累積尚未生效時扣回不會使餘額為負
- [x] 一連串入帳、折抵、取消、到期之後，帳本總和與可用餘額仍一致（有測試）

**做法備註**：累積發生在付款完成、取消只允許在 pending，因此「扣回已累積的購物金」
這條路目前經公開流程走不到（已付款的訂單不能取消）。`reverseForOrder` 兩邊都做，
但只有折抵回沖是可觀察的；扣回那一半以直接寫入帳本的測試證明它不會讓餘額變負數。
部分退貨進模型時，那一半才會被真的用到。
