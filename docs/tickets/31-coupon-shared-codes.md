# 31 — 優惠券模型與公開共用碼

**What to build:** 顧客可以在結帳前輸入一組公開折扣碼並看到金額變化。經營者可以建立、設定期間、停用這組碼。每一次核銷都留下明細 —— 那份明細之後就是行銷分析的資料來源。核銷發生在結帳的同一個交易內，與訂單一起成敗。

**Blocked by:** 10, 28

**Status:** done

- [x] 券指向一條促銷規則，有唯一的碼、狀態與有效期間
- [x] 顧客輸入有效碼會折價，無效時錯誤原因明確區分不存在、已過期、已停用、不符資格
- [x] 核銷在結帳的同一個交易內完成，訂單失敗則核銷不成立
- [x] 每次核銷寫入明細：哪張券、哪條規則、哪張訂單、折抵多少、何時
- [x] 套用券的端點受節流保護
