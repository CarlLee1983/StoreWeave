# 97 — 形象站可以登入、註冊與重設密碼

**What to build:** 一個用 base release 建的網站終於有會員入口。訪客可以自己註冊成 Member、登入、忘記密碼時自己重設。形象站沒有商務資料，所以註冊只建立 Account，不建立 Customer，也不需要載入購物車模組。

這是這批工作對使用者而言最實在的產出——Theme 早就畫得出登入表單、角色目錄早就有可以自助註冊的 Member，缺的一直只是路由。

**Blocked by:** 95, 96

**Status:** done

- [x] `platform-auth` 進形象站的模組清單
- [x] 形象站不傳註冊命令，走認證服務自己的註冊；只建立 Account
- [x] 形象站的登入、註冊、忘記密碼、重設密碼、登出全部可用
- [x] 形象站的登入路徑不要求購物車模組，也不做任何購物車合併
- [x] 因為模組數改變而失準的數字型斷言一併更新
