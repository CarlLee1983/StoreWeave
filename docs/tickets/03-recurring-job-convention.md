# 03 — 週期性工作的自我續排慣例

**What to build:** 專案有了一套可重複使用的做法，讓一件工作可以每隔固定時間再跑一次。平台的工作佇列只支援「指定時間執行一次」，沒有排程器，因此週期性必須靠工作自己在結束時排下一次；去重鍵每次必須不同，否則會被唯一約束擋掉。後面的購物車清理、生日發券、等級重算都建立在這張票上。

**Blocked by:** None — can start immediately

**Status:** done

- [x] 有一個共用的方式可以把任一個工作宣告成週期性的，呼叫端不必自己處理去重鍵
- [x] 工作失敗重試時不會造成續排斷鏈或重複續排
- [x] 有測試以可注入的時間驗證連續數個週期都正確排入
- [x] 既有的訂單過期工作行為不受影響
