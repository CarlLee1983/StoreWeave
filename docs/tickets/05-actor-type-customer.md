# 05 — Actor 型別新增顧客，並收斂前台角色

**What to build:** 系統的身分模型認得「顧客」這種人，與後台操作者、服務、擴充套件、系統並列。同時，匿名前台角色不再持有無範圍限制的訂單讀取權限。這張票只做型別與權限常數的擴充，還沒有人能真的登入成顧客。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 身分型別新增顧客成員，所有窮舉分支處都顯式處理它
- [ ] 內建角色新增顧客角色，其權限僅足以讀商品與庫存、建立與讀取訂單、讀寫自己的資料
- [ ] 匿名前台角色不再持有無範圍的訂單讀取權限
- [ ] 稽核紀錄能區分顧客與後台操作者
- [ ] 既有測試全綠
