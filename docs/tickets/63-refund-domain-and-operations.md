# 63 — 已付款訂單退款模型與後台作業

**What to build:** 新增獨立於取消的退款領域模型、command 與後台操作。第一版可限制整單退款，
但資料模型與稽核紀錄不能排除日後部分退款。

**Blocked by:** 58

**Status:** ready-for-agent

- [ ] 退款記錄原付款、金額、原因、操作者、狀態、provider reference、請求與完成時間
- [ ] 只有已付款且未完成退款的訂單可請求退款；金額不能超過可退額且重送不可建立重複退款
- [ ] 退款與退貨／出貨關係明確：非出貨訂單可直接退款，已出貨訂單由 65 的 RMA 決定退款時機
- [ ] 後台看得到退款隊列、失敗原因與安全重試入口；顧客訂單頁只顯示必要狀態
- [ ] 為狀態轉換、授權、雙重送出與稽核紀錄建立 integration tests

## 不做的事

- 呼叫任何特定金流退款 API（64）、退貨／換貨（65）、發票折讓（66）。
