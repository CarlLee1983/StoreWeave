# 40 — 購物金帳本與付款後入帳

**What to build:** 顧客付款完成後獲得購物金，並在設定的天數之後開始可用。餘額不是一個欄位，而是由帳本推導出來 —— 帳本只增不改，因此永遠對得起來。

**Blocked by:** 14, 15

**Status:** done

- [x] 購物金以只增不改的分批帳本記錄，每批有來源、生效日與到期日
- [x] 可用餘額由帳本推導，排除未生效與已過期的批次，且先到期的先使用
- [x] 付款完成時入帳，生效天數與累積比例由後台設定
- [x] 餘額推導的純函式有涵蓋時間邊界的單元測試
- [x] 顧客可查詢自己的餘額與每一筆分錄

**已拍板（2026-08-22）**：累積比例 1%、付款後 7 天生效、發放後 365 天到期。
七天涵蓋多數退貨期；到期日從**生效日**起算，否則等待期會白白吃掉可用時間。
