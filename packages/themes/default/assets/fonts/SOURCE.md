# Default Theme 字型來源

這兩個字型檔是 Default Theme 的同源靜態資產，不由瀏覽器向第三方字型 CDN 請求。

- `NotoSansTC-Variable.woff2`：由 Google Fonts [`ofl/notosanstc/NotoSansTC[wght].ttf`](https://github.com/google/fonts/tree/main/ofl/notosanstc) 於 2026-08-23 轉換而來。
- `NotoSerifTC-Variable.woff2`：由 Google Fonts [`ofl/notoseriftc/NotoSerifTC[wght].ttf`](https://github.com/google/fonts/tree/main/ofl/notoseriftc) 於 2026-08-23 轉換而來。
- 各字型在 Google Fonts 的原始 SIL Open Font License 1.1 通知會隨 release 發送：[`NotoSansTC-OFL.txt`](./NotoSansTC-OFL.txt) 與 [`NotoSerifTC-OFL.txt`](./NotoSerifTC-OFL.txt)。檔案逐位元組保留官方來源內容。

轉換保留可變字重，不做字元子集化；商品名稱與描述可使用任意繁體中文內容。產物僅應由應用程式以 `/theme/default/fonts/` 提供。
